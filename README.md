# Rock-Paper-Scissors
Rock Paper Scissors
Overview
Simple command-line rock paper scissors game where you play against the computer. 

How To Run
Have Python3 installed
Navigate to project directory
Run the game, ‘python rPS.py’ or ‘python3 rPS.py’

How To Play

When prompted:
Enter:
r for Rock
p for Paper
s for Scissors

The computer will randomly choose its move 
The winner is decided through normal rock paper scissors rules
Stats related to wins/losses/ties are tracked throughout the session and will be relayed back to you after you quit

Rules
Scissors beats paper
Paper beats rock
Rock beats scissors
Matching choices results in a tie
